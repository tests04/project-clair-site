Project Clair プライバシーポリシー

最終更新日：2026年9月28日

対象

Project Clair（以下「本ツール」）は、開発者本人のみが個人で利用するツールです。第三者の Google アカウントのデータは扱いません。

取得するデータ

本ツールは、Google の OAuth 認証を通じて、本人の Gmail の受信トレイにある未読メールの件名・送信者・本文・受信日時を読み取ります（gmail.readonly 権限）。メールの送信・削除・変更は行いません。

データの利用目的

取得したメールの内容は、返信や対応が必要かどうかの判定、要約、期限の抽出に使い、本人用の ToDo 一覧を作るためだけに利用します。

データの保存場所と外部への送信

  • 取得したデータと処理結果は、本人が管理する PC 上にのみ保存します
  • 要約はその PC 上で動くローカルの AI で行います
  • 対応要否の判定のために、メールの本文を外部の判定サービス（TypeSafe AI 社の Jev）に送信します。送信前に、人名・電話番号・メールアドレスなどを記号に置き換えます
  • 上記以外の第三者にデータを提供・販売することはありません。広告には利用しません

Google ユーザーデータの取り扱い

本ツールによる Google API から取得した情報の使用は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

データの削除

本人は、PC 上のデータベースを削除することで、いつでもデータを消去できます。Google アカウントの設定から、本ツールへのアクセス許可を取り消すこともできます。
